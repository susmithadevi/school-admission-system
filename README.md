# AdmitSchool — School Admission System

**Task ID:** WD-SCH-004 · **Student Code:** DAS-SCH-004 · **Domain:** School Admission / Web Development · **Company:** Data Alcott Systems

A responsive frontend-only school admission management demo built with HTML5, CSS3 and JavaScript.

## Features
- Dashboard with admission statistics and charts
- Student registration with validation
- Application listing, search, filters, detail/edit modal and CSV export
- Simulated document upload records
- Application review with comments, shortlist, admit and reject actions
- Entrance exam score entry
- Merit ranking using 60% academic + 40% entrance score where available
- Simulated fee tracking
- Printable admission offer letter
- Course-wise and status-wise reports
- Dark mode, responsive sidebar and localStorage persistence

## Run locally
Download the files and open `index.html` in a modern browser. No install, server, or database is required.

## Demo limitations
This is a frontend educational prototype. Login/roles are not connected to backend authentication. Document upload records the selected filename only; no file is transmitted. Fee payments are simulated. Data is saved in the current browser's localStorage. Sample student records are fictional.

## Files
- `index.html` — page structure
- `style.css` — responsive design and dark mode
- `script.js` — interactions, demo data and localStorage
- `PROJECT-REPORT.md` — short project report
